# Extra/Learn python

Vendored Grok `/learn` helpers (stdlib). This folder is `<skill dir>` for Extra/Learn askmode.

Upstream: `$GROK_HOME/bundled/skills/learn/`. Refresh by copying those files here.

| File | Role |
| --- | --- |
| `collect_sessions.py` | Estimate, collect sessions, write a run directory |
| `state.py` | `get` `set` `wait` `decide` `trash` `restrict` `clear` |
| `learn-traces.rhai` | Sibling the collector hashes; map-reduce workflow |
| `signals.md` | Mapper/reducer extract spec |
| `report-format.md` | `report.md` and `actions.json` shape |

Run artifacts still go under `$GROK_HOME/learn/`.
